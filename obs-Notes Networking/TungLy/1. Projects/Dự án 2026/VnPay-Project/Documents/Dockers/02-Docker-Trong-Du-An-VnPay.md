## Docker được dùng để làm gì trong HRM?
Trong dự án HRM VnPay, Docker dùng để:

Chạy Web / API / Service đồng bộ

Dùng chung Redis, DB, Traefik

Dễ chạy local, debug, demo

Docker đứng giữa code và hạ tầng, giúp dev không cần hiểu sâu server.
