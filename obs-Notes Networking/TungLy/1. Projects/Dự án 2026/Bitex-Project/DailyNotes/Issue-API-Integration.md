## Bối cảnh

Dự án Bitex yêu cầu **HRM gọi API của Khách hàng** để lấy dữ liệu — không chỉ import file tĩnh mà tích hợp real-time qua API.

---

## Yêu cầu kỹ thuật

1. HRM gọi API phía KH để **lấy dữ liệu**
2. Trao đổi chi tiết về **cách hoạt động của API**
3. Xác định cách **lấy dữ liệu** (endpoint, auth, format)
4. **Mapping hệ thống**: trường dữ liệu KH → HRM
