# Synthesis

Thư mục này chứa các phân tích tổng hợp, so sánh, insight được tạo ra từ quá trình query và khám phá wiki.

**Chưa có synthesis nào.**

## Khi nào tạo synthesis?

Khi trả lời một câu hỏi phân tích quan trọng (so sánh, lessons learned tổng hợp, pattern nhận ra), LLM sẽ lưu kết quả vào đây thay vì chỉ trả lời trong chat.

Ví dụ:
- `synthesis/lessons-learned-net8.md` — tổng hợp bài học từ các dự án upgrade
- `synthesis/khach-hang-san-xuat-vs-dich-vu.md` — so sánh pattern triển khai
