# Phỏng Vấn Ứng Viên SE Backend — VnResource 2024

## Tóm tắt

Hồ sơ và đánh giá 4 ứng viên SE Backend được phỏng vấn tại VnResource năm 2024. Cả 4 đều **PASS**. Tài liệu ghi lại phân tích CV, điểm mạnh/yếu, đánh giá kỹ năng theo tiêu chí công ty, và câu hỏi phỏng vấn đề xuất.

## Key Takeaways

### Thái Bảo An — 20/06/2024 (PASS — Thực tập Back End)
- Sinh viên năm 3 UEH, ngành Khoa học Dữ liệu, GPA 3.56/4.0
- Stack: SQL, Python, Power BI — chưa có .NET/C#
- Điểm mạnh: GPA cao, chứng chỉ Google Data Analytics + IBM Data Science + HackerRank SQL Advanced
- Điểm yếu: Tiếng Anh trung cấp (TOEIC 625), kỹ năng xử lý dữ liệu lớn 50%
- **Nhận xét**: Phù hợp vị trí thực tập/tập sự, nền tảng phân tích tốt

### Mã Tấn Vĩnh — 19/07/2024 (PASS — Back End chính thức)
- Sinh năm 1985, Đại học Sư phạm Kỹ thuật TP.HCM
- 8 năm kinh nghiệm: OSSTECH (nhân sự/tòa nhà/năng lượng) + Amaris VN (Abbott/Bosch)
- Stack: .NET Core C#, Java, Spring MVC, Docker, MySQL/MSSQL/Oracle/PostgreSQL
- Đánh giá: C# 8/10, SQL 8/10, MVC 7/10, Web API 7/10
- **Nhận xét**: Nền tảng kỹ thuật vững, cần cải thiện kỹ năng mềm và cập nhật công nghệ AI/Cloud

### Nguyễn Hoàng Trung — 10/10/2024 (PASS — Back End)
- Đại học Khoa học Tự nhiên TP.HCM, CNTT
- Kinh nghiệm: Lac Viet (5 tháng) + Freelancer 2 năm
- Stack: C#/.NET Core, TypeScript, Angular, ReactJS, Azure, Power BI, IIS, SQL Server/MongoDB
- Đánh giá: C#/.NET Core 9/10, Angular/ReactJS 8/10, SQL 7/10, Azure 7/10, Giao tiếp 5/10
- **Nhận xét**: Kỹ thuật xuất sắc, đặc biệt .NET Core + Azure. Cần cải thiện kỹ năng mềm

### Trần Công Duy — 10/10/2024 (PASS — Back End)
- Địa chỉ: Bình Thạnh TP.HCM
- Kinh nghiệm: Logsik Technology (3 tháng thực tập + 3 tháng thử việc — dự án AI annotation Viettel)
- Stack: C#, Java, ASP.NET MVC, Spring MVC, SQL Server/MySQL, LINQ, RESTful API
- Đánh giá: C# 8/10, SQL 8/10, ASP.NET MVC 8/10, Java 7/10, RESTful API 7/10
- **Nhận xét**: Ứng viên junior có tiềm năng, cần phát triển kỹ năng quản lý dự án

## Trích dẫn quan trọng

> Nguyễn Hoàng Trung có nền tảng vững chắc với .NET Core, từng phát triển nhiều hệ thống backend phức tạp. Tuy nhiên, kỹ năng mềm còn hạn chế, cần phát triển thêm trong giao tiếp và làm việc nhóm.

> Mã Tấn Vĩnh đủ điều kiện là nhân viên chính thức tại công ty VnResource.
