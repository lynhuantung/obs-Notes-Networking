### 4. Quy trình quét source .NET

- Nội dung chính:
    
    - 3 bước:
        
        1. `begin` → khai báo project + token.
            
        2. `msbuild` → build & thu thập dữ liệu.
            
        3. `end` → đẩy dữ liệu lên SonarQube.
            
    - Chạy trong Developer Command Prompt, không dùng GUI.
