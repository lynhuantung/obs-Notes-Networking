## 5️⃣ Hiệu suất thực hiện công việc (USP)

- **Giá trị:** 21%
    

### 📌 Cách tính:

- Nghỉ phép + lễ: **13 ngày**
    
- USP tháng 3 (nguồn bảng điều phối): **82**
    
- USP trung bình ngày:
    
    ```
    USP/ngày = USP chuẩn tháng / 25 = 6.84
    ```
    

### 📌 Công thức:

```
% = ((USP/ngày × số ngày nghỉ + tổng USP 3 tháng) / 3) / 127.5
```

### 📌 Áp dụng:

```
% = ((6.84 × 13 + 82) / 3) / 127.5 ≈ 21%
```
