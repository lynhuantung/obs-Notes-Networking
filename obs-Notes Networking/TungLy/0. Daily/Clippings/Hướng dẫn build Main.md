**Tổng quan:** Trang hướng dẫn cách build project HRM9 trên server, dành cho các source code từ version v8.9.14 trở lên.

**Mục đích:** Hướng dẫn chi tiết từng bước để thực hiện build project thành công.

**Nội dung chi tiết:**
1.  Truy cập Project build qua đường dẫn được cung cấp.
2.  Chọn project HRM9, sau đó chọn Build and Release.
3.  Chọn Definitions để chọn agent build (HRM-Builder-SV21, HRM-Builder-SV47, HRM-Builder).
4.  Chọn build và điều chỉnh thông tin build nếu cần thiết.

**Kết luận:** Trang cung cấp hướng dẫn từng bước để build project HRM9, giúp người dùng thực hiện quy trình này một cách chính xác.
