## 1\. Mục đích

---

Thiết lập quy chuẩn cho việc **tạo Pull Request** và **đặt tên Commit**, nhằm:

- Đảm bảo rõ ràng, nhất quán trong quá trình phát triển.
- Hỗ trợ reviewer đánh giá nhanh và chính xác.
- Dễ dàng truy vết và quản lý lịch sử thay đổi.

## 2\. Tiêu chuẩn Pull Request

- **Tiêu đề**: đảm bảo xác định chính xác task (amis, jira)
- **Mô tả**: đảm bảo mục đích và những thay đổi

---

![](https://amisapp.misa.vn/Notes/APIS/g1/DocumentAPI/api/Image?tenantCode=1O4AZTLN&storageType=12&isResize=false&path=1ab5fbcb-b91a-4ec4-9827-aa43edb766eb.png)

### 2.1. Tiêu đề (Title)

- **Định dạng**:
```
[ID TASK] - Mô tả ngắn gọn thay đổi
```
- **ID TASK**: Lấy từ hệ thống quản lý công việc (Amis, Jira...).
- **Mô tả ngắn**: Rõ ràng, ≤ 80 ký tự.
- **Ví dụ**:
```
[HRM-168] - Điều chỉnh giao diện form đánh giá thử việc
[CRM-245] - Fix lỗi hiển thị dữ liệu khách hàng khi tìm kiếm
```

### 2.2. Nội dung mô tả (Description)

### Mô tả mục đích và ảnh hưởng

Ví dụ:

### 🎯 Mục đích & Thay đổi

- Fix bug hiển thị ngày sai trong Báo cáo công
- Tối ưu query load dữ liệu nhanh hơn

### 🔍 Ảnh hưởng & Kiểm tra

- Ảnh hưởng: Màn hình Báo cáo công
- Rủi ro: Load sai nếu query chưa tối ưu
- Test: Mở Báo cáo công → Chọn kỳ công → Ngày hiển thị đúng, load < 2s

### 2.3. Reviewer

- Ít nhất **01 reviewer chính** và **01 reviewer dự phòng**.
- Tag reviewer theo module liên quan.

### 2.4. Checklist trước khi tạo PR

- Code build thành công.
- Đã test local.
- Không còn file rác, log debug.

## 3\. Tiêu chuẩn Commit Message

---

### 3.1. Định dạng commit

- **Định dạng ngắn gọn**:
```
[type] - mô tả công việc
```
- **type**:
	- `feat` → thêm tính năng mới.
	- `fix` → sửa lỗi.
	- `refactor` → cải tiến code, không đổi chức năng.
	- `chore` → thay đổi cấu hình, build, tool.
- **Mô tả**: Mã task từ hệ thống quản lý công việc (Amis, Jira), tiêu đề task (trong amis hoặc jira **phải thể hiện "IDTask"** và mô tả).
- **Ví dụ**:
```
feat - [SYS Modify] QPVN2121 - Thêm logic trim các trường nhập text ở các màn hình trên hệ thống
fix - [CRM245] xử lý lỗi hiển thị danh sách khách hàng
```
