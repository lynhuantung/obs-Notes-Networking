# SQLTools

Cho phép tìm và xóa dữ liệu có tham chiếu của một bảng trong một cơ sở dữ liệu

# 1. Link SQLTools

## Thông tin link SQLTools

### [Link SQL Tools 🎁](https://docs.vnresource.net/web-sqltool)

### UserName : `u01`

### Password : `asd@123`

### Hình ảnh SQLTools

#### - Vùng nhập thông tin SQL

#### - Vùng Query : Viết câu lệnh sql

#### - Vùng Grid : Hiển thị danh sách trên lưới từ câu lệnh từ vùng query

#### - Vùng Excute - Query : từ vùng grid chọn, click vào nút `Excute - query` sẽ sinh ra lưới ở vùng data

#### - Vùng Data : Hiển thị dữ liệu bao gồm thông tin khóa ngoại được chọn ở vùng Grid

#### - Vùng Delete Command : danh sách dữ liệu cần delete (sinh ra câu lệnh delete)

#### - Vùng Excute - Delete Command : vùng xóa dữ liệu khỏi database
