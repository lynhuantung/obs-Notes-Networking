# Tóm tắt

---

**5 ý chính:**

1. **Giới thiệu công cụ:** Trình bày công cụ giám sát Memory Leak & GC Diagnostics nhằm phát hiện tình trạng memory leak từ các biến `static`. 2
2. **Theo dõi RAM realtime:** Hỗ trợ Load dữ liệu RAM từ nhiều service/pod và phân tích theo từng instance. 3
3. **Snapshot & Delta:** Cho phép Snapshot và Export Report để theo dõi tăng/giảm bộ nhớ theo thời gian. 2
4. **GC Diagnostics:** Theo dõi Working Set, Managed Heap, GC Gen2, ThreadPool để đánh giá sức khỏe ứng dụng. 4
5. **Giải phóng cache:** Hỗ trợ xóa field cache để kiểm tra khả năng giải phóng RAM realtime và xác định field nghi ngờ leak. 5

## Mục tiêu:

- Giới thiệu công cụ giám sát Memory Leak cho hệ thống HRM.
- Hướng dẫn workflow phân tích RAM và GC Diagnostics.
- Thống nhất cách theo dõi và xử lý field nghi ngờ leak.

## 📝Các ý chính

- Giới thiệu cơ chế phát hiện memory leak từ các biến static.
- Trình bày chức năng Load, Snapshot, Export Report và GC Diagnostics.
- Thảo luận workflow xử lý:
    - Load dữ liệu RAM.
    - Snapshot làm mốc so sánh.
    - Theo dõi delta tăng giảm.
    - Xác định field nghi ngờ leak.
    - Kiểm tra GC Diagnostics sau khi giải phóng RAM.
- Thống nhất ưu tiên theo dõi các field lớn (>1 MB).
- Chỉ xóa cache khi xác định an toàn và có thể reload lại dữ liệu.
- Theo dõi thêm các pod có dấu hiệu tăng RAM bất thường.

## Action tiếp theo:

1. Theo dõi các field có kích thước lớn và tăng liên tục theo thời gian.
2. Rà soát các cache static có nguy cơ gây memory leak.
3. Kiểm tra thêm GC Gen2 và ThreadPool tại các pod có RAM tăng bất thường.
4. Tiếp tục monitor trên môi trường vận hành thực tế để tối ưu cache và hiệu năng hệ thống.
