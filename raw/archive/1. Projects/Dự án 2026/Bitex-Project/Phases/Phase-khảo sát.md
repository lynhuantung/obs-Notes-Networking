# Giai đoạn: Khảo sát và Chốt SRS
---

**Thời gian:** 02/06/2025 - 30/06/2025  
**Trạng thái:** ✅ Hoàn thành

## Mục tiêu
- Khảo sát nghiệp vụ KH, hiểu rõ yêu cầu
- Chốt tài liệu SRS (Software Requirement Specification)
- Lên task list ban đầu cho SE

## Công việc

### Khảo sát nghiệp vụ
- Thu thập yêu cầu các phân hệ: Nhân sự, Lương, Bảo hiểm, Chấm công
- Xác định phạm vi tích hợp với hệ thống hiện có của KH
- Chốt danh sách phân hệ triển khai

### Tích hợp API (12/07/2025 — kéo sang đầu giai đoạn Cài đặt)
- HRM gọi API của KH để lấy/đồng bộ dữ liệu
- Trao đổi nội dung: cách hoạt động, lấy dữ liệu, mapping hệ thống
- PE cần tài liệu API sớm để raise task list lên SE
- Phạm Văn Hiển (TCDA) hỗ trợ điều phối SE tham gia buổi API

### Đầu ra giai đoạn
- Tài liệu SRS đã chốt
- Danh sách task AKW trên AMIS
- Tài liệu API từ KH

## Rủi ro
- Tài liệu API từ KH có thể trễ → delay task list cho SE
- Thiếu môi trường dựng Linux để test tích hợp
  - Ứng phó: nhờ IT dựng môi trường Linux

## Ghi chú
- Dự án quản lý chung 2 hợp đồng Bitex + AKW trên cùng 1 dự án AMIS
- Về hạch toán: chia đôi chi phí theo 2 hợp đồng
