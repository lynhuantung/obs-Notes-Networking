### 8.3.1 Giải pháp phải hỗ trợ tích hợp Single Sign-On (SSO) với Identity Provider là Microsoft Azure Active Directory (Azure AD) và LDAP, bao gồm các giao thức OAuth 2.0, OpenID Connect, và SAML 2.0. Nhà thầu cần cung cấp tài liệu hướng dẫn chi tiết về quy trình tích hợp

> Tích hợp Single Sign-On (SSO) --- Azure AD, LDAP, OAuth2, OpenID Connect, SAML2
>
> ![[image138.png]]
>
> Giải pháp VnResource HRM hỗ trợ đầy đủ cơ chế xác thực Single Sign-On (SSO) thông qua các giao thức chuẩn công nghiệp:
>
> OAuth 2.0
>
> OpenID Connect (OIDC)
>
> SAML 2.0
>
> LDAP
>
> Hệ thống hỗ trợ tích hợp với các Identity Provider phổ biến:
>
> Microsoft Azure Active Directory (Azure AD / Entra ID)
>
> Microsoft Active Directory (LDAP)
>
> ADFS
>
> Keycloak
>
> Okta
>
> Google Identity
>
> Kiến trúc xác thực sử dụng IdentityServer4 làm Authorization Server trung tâm, đóng vai trò cầu nối giữa hệ thống HRM và Identity Provider của khách hàng.
>
> Luồng xác thực SSO:
>
> Người dùng truy cập hệ thống HRM
>
> Hệ thống redirect đến Azure AD hoặc LDAP/ADFS
>
> Người dùng xác thực bằng tài khoản doanh nghiệp
>
> Identity Provider trả về Authorization Code/Token
>
> IdentityServer4 cấp JWT Access Token và Refresh Token
>
> Người dùng truy cập toàn bộ hệ thống mà không cần đăng nhập lại
>
> Hệ thống hỗ trợ:
>
> JWT Token Authentication
>
> Refresh Token
>
> Token Revocation
>
> RBAC phân quyền theo Role/Scope
>
> Scope riêng cho từng client/service
>
> Redis Token Blacklist
>
> HTTPS/TLS bảo mật kết nối
>
> Đối với LDAP/Active Directory:
>
> Hỗ trợ đồng bộ user từ AD về HRM
>
> Mapping tự động thông tin user, email, đơn vị
>
> Đồng bộ phân quyền và organizational structure
>
> Nhà thầu cam kết cung cấp đầy đủ tài liệu triển khai và tích hợp SSO bao gồm:
>
> Integration Blueprint
>
> API Catalog
>
> OAuth/OIDC Endpoint
>
> Azure AD App Registration Guide
>
> Claim & Attribute Mapping
>
> JWT/Refresh Token Flow
>
> Hướng dẫn cấu hình LDAP/AD
>
> Quy trình xử lý token và revoke token
>
> Tài liệu troubleshooting và trace lỗi xác thực
>
> Giải pháp giúp SSI dễ dàng tích hợp hệ thống nhận diện tập trung, nâng cao bảo mật và tối ưu trải nghiệm người dùng trong toàn hệ sinh thái ứng dụng.
