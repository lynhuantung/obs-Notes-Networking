### 10.8.5 Trường hợp sử dụng nền Java, phần mềm và các công cụ hỗ trợ cài đặt trên máy trạm phải sử dụng Java có phiên bản phù hợp với SSI.

> Giải pháp VnResource HRM không sử dụng nền tảng Java cho ứng dụng chính trên máy trạm. Hệ thống được phát triển trên nền .NET/C# và vận hành theo mô hình web-based, người dùng chỉ cần sử dụng trình duyệt Chrome/Edge mà không cần cài đặt Java Runtime trên máy trạm.
>
> Trong trường hợp có thành phần hoặc công cụ bên thứ ba sử dụng Java (ví dụ: Apache JMeter hoặc công cụ kỹ thuật hỗ trợ), VnResource cam kết sử dụng phiên bản Java phù hợp với tiêu chuẩn và chính sách CNTT của SSI.
