Giải thích

Infrastructure as Code (IaC) cho phép quản lý hạ tầng bằng code thay vì thao tác thủ công.

Hạ tầng có thể được triển khai, cập nhật hoặc tái tạo tự động và nhất quán giữa các môi trường.
