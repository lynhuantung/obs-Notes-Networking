### 10.2.3 \[Đáp ứng\] Nhà thầu vui lòng cung cấp cơ sở tính toán của việc đề xuất cấu hình phần cứng của hệ thống máy chủ. Đồng thời cung cấp tài liệu tham chiếu về khách hàng của họ đã sử dụng máy chủ tương tự bao gồm thông tin về các đặc tả kỹ thuật phần cứng máy chủ, sơ đồ triển khai, vv

##### Cơ sở tính toán cấu hình phần cứng đề xuất

> Cấu hình phần cứng đề xuất của VnResource HRM được xây dựng dựa trên:
>
> Yêu cầu Non-Functional Requirements (NFR)
>
> Số lượng người dùng đồng thời
>
> Mô hình triển khai High Availability (HA)
>
> Kiến trúc scale-out và khả năng tăng trưởng trong tương lai
>
> Các tham số sizing chính:
>
> 5.000 user đồng thời (baseline)
>
> Khả năng mở rộng đến 10.000 user đồng thời
>
> Thời gian phản hồi ≤ 3 giây với 99% thao tác nghiệp vụ thông thường
>
> Kiểm thử hiệu năng bằng JMeter theo nhiều kịch bản nghiệp vụ thực tế

##### Cơ sở sizing Application Server

> Cấu hình đề xuất:
>
> CPU 16 Cores
>
> RAM 64 GB+
>
> SSD 240 GB+
>
> Cơ sở tính toán:
>
> Kiến trúc .NET stateless hỗ trợ scale-out
>
> Session/token lưu Redis tập trung
>
> Tối ưu cho concurrent session và thread pool processing
>
> Dự phòng tài nguyên cho peak load và future growth
>
> Hệ thống triển khai tối thiểu:
>
> 02 App Server Active/Active phía sau Load Balancer

##### Cơ sở sizing Database Server

> Cấu hình đề xuất:
>
> CPU 16 Cores+
>
> RAM 128 GB
>
> SSD 512 GB+
>
> Cơ sở tính toán:
>
> SQL Server buffer pool cho workload OLTP lớn
>
> Tối ưu cache hot data và giảm disk I/O
>
> Hỗ trợ đồng thời giao dịch nghiệp vụ và báo cáo
>
> Dự phòng cho replication, backup và transaction log
>
> Database triển khai:
>
> SQL Server AlwaysOn Active/Passive
>
> High Availability và Disaster Recovery
