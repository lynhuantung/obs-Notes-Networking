### 10.1.3 Hệ thống đề xuất phải hỗ trợ khả năng active-passive (active/active) clustering và cân bằng tải (Load Balancing) cho các thành phần. Nhà thầu đề xuất và mô tả chi tiết về mô hình triển khai.

##### Clustering & Load Balancing --- Mô hình triển khai

> ![[image137.png]]
>
> Giải pháp VnResource HRM hỗ trợ đầy đủ mô hình clustering và cân bằng tải (Load Balancing) cho các thành phần hệ thống nhằm đảm bảo tính sẵn sàng cao (High Availability), khả năng mở rộng và duy trì dịch vụ liên tục.

##### 1. Application Layer --- Active/Active Clustering

> Tầng ứng dụng được triển khai theo mô hình:
>
> Active/Active
>
> Nhiều App Server chạy song song
>
> Stateless architecture
>
> Phía trước hệ thống là:
>
> Load Balancer (Nginx/HAProxy/Ocelot)
>
> Health check tự động
>
> SSL termination
>
> Retry routing
>
> Load Balancer hỗ trợ:
>
> Round Robin
>
> Least Connection
>
> Tự động loại node lỗi khỏi pool
>
> Tự động chuyển tải sang node còn lại khi xảy ra sự cố
>
> Session và token được lưu tập trung trên Redis Cache, giúp:
>
> Không mất session khi failover
>
> Hỗ trợ scale-out dễ dàng
>
> Có thể bổ sung App Node mới mà không ảnh hưởng hệ thống hiện tại
>
> Hệ thống hỗ trợ:
>
> Horizontal scaling
>
> Zero-downtime deployment
>
> Rolling update
>
> Retry sang node khác khi node quá tải

##### 2. Database Layer --- Active/Passive Clustering

> Database triển khai theo mô hình:
>
> SQL Server Active/Passive
>
> AlwaysOn Availability Group
>
> Hoặc Log Shipping/Mirroring
>
> Cơ chế hoạt động:
>
> Primary xử lý toàn bộ read/write
>
> Secondary đồng bộ dữ liệu liên tục
>
> Failover tự động hoặc bán tự động khi Primary gặp sự cố
>
> Kiến trúc hỗ trợ:
>
> High Availability
>
> Data replication
>
> Backup & restore
>
> Disaster Recovery

##### 3. Redis Cache Cluster

> Redis triển khai theo mô hình:
>
> Redis Sentinel / Redis HA
>
> Chức năng:
>
> Session cache
>
> Token cache
>
> Distributed cache
>
> Redis giúp:
>
> Giảm tải Database
>
> Tăng tốc độ phản hồi
>
> Đồng bộ session giữa các App Server

##### 4. File Storage Cluster

> Hệ thống hỗ trợ:
>
> NFS Shared Storage (On-Premise)
>
> AWS S3 / Object Storage (Cloud)
>
> File storage dùng chung giữa các App Node nhằm đảm bảo:
>
> Tính nhất quán dữ liệu
>
> Hỗ trợ scale-out
>
> Hỗ trợ backup và replication

##### 5. Mô hình triển khai tổng thể

> Kiến trúc triển khai bao gồm:
>
> WAF/Firewall
>
> Load Balancer Cluster
>
> Application Server Cluster (Active/Active)
>
> Redis Cache Cluster
>
> SQL Server Cluster (Active/Passive)
>
> Shared Storage/S3
>
> DR Site
>
> Hệ thống hỗ trợ:
>
> High Availability (HA)
>
> Automatic failover
>
> Load balancing đa tầng
>
> Disaster Recovery (DR)
>
> Horizontal scaling
>
> Kiến trúc này giúp hệ thống đáp ứng yêu cầu hiệu năng cao, khả năng mở rộng linh hoạt và đảm bảo hoạt động liên tục cho hệ thống HRM của SSI.
