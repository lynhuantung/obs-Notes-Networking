### 10.4.2 \[Đáp ứng\] Mô hình đề xuất của nhà thầu phải tương thích với hệ thống hiện tại của SSI ở mức cao nhất.

> VnResource HRM cam kết mô hình triển khai đề xuất tương thích ở mức cao nhất với hạ tầng và hệ thống hiện tại của SSI, đảm bảo dễ tích hợp, vận hành ổn định và không làm thay đổi kiến trúc CNTT hiện hữu.
>
> Giải pháp tương thích với:
>
> Hạ tầng On-Premise, Cloud hoặc Hybrid Cloud
>
> Mô hình mạng phân vùng Public/App/Database của SSI
>
> Active Directory / LDAP / SSO
>
> ESB / API Gateway / Data Platform / ERP
>
> Docker, Kubernetes và môi trường ảo hóa VMware/Hyper-V
>
> Hệ thống sử dụng:
>
> Windows Server 2022 và RHEL 9.x trên kiến trúc x86-64
>
> SQL Server 2019+
>
> REST API / HTTPS / JSON theo chuẩn mở
>
> OAuth2, OpenID Connect, mTLS và JWT
>
> Giải pháp web-based, không yêu cầu cài đặt client tại máy người dùng, hỗ trợ truy cập qua mạng LAN/WAN/VPN hiện có của SSI.
>
> Ngoài ra:
>
> Hệ thống hỗ trợ chế độ internal-only, không cần Internet-facing nếu SSI yêu cầu.
>
> Kiến trúc stateless và modular cho phép tích hợp thêm hệ thống mới mà không ảnh hưởng hệ thống hiện hữu.
>
> Hỗ trợ centralized logging, monitoring và security policy theo chuẩn enterprise.
>
> VnResource sẽ phối hợp cùng SSI trong giai đoạn triển khai để rà soát topology mạng, firewall policy, IAM/SSO và các hệ thống tích hợp nhằm đảm bảo mức độ tương thích tối đa với hạ tầng hiện tại của SSI.
