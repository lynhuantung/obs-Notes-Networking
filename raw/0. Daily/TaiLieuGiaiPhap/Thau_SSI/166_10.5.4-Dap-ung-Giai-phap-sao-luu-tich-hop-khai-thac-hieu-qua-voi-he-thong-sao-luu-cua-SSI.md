### 10.5.4 \[Đáp ứng\] Giải pháp sao lưu tích hợp, khai thác hiệu quả với hệ thống sao lưu của SSI

> VnResource HRM hỗ trợ tích hợp linh hoạt với hệ thống sao lưu hiện có của SSI nhằm tận dụng tối đa hạ tầng backup enterprise, giảm chi phí đầu tư và đồng bộ chính sách vận hành.
>
> Các mô hình tích hợp được hỗ trợ:
>
> SQL Server Agent Backup:
>
> Backup trực tiếp từ SQL Server Passive/Replica
>
> Tích hợp SQL Plugin/Agent của hệ thống backup SSI
>
> Native SQL Backup:
>
> SQL Server backup ra file
>
> Đồng bộ vào NAS/SAN hoặc Backup Repository của SSI
>
> File Server Backup:
>
> Backup file hồ sơ, chứng từ từ NFS/File Server
>
> Hỗ trợ SMB/NFS mount và backup agent
>
> Cloud/Object Storage:
>
> Đồng bộ backup sang S3/Object Storage
>
> Hỗ trợ long-term archive và DR
>
> Giải pháp đảm bảo:
>
> Không backup trùng lặp
>
> Không ảnh hưởng hiệu năng production
>
> Backup compression và deduplication
>
> Tích hợp retention policy hiện có của SSI
>
> Đồng bộ backup schedule với backup window của SSI
>
> Ngoài ra:
>
> Backup job có monitoring và alert tập trung
>
> Hỗ trợ restore theo thời điểm (Point-in-time Recovery)
>
> Hỗ trợ DR replication và multi-site backup
>
> Tương thích với centralized logging và monitoring của SSI
