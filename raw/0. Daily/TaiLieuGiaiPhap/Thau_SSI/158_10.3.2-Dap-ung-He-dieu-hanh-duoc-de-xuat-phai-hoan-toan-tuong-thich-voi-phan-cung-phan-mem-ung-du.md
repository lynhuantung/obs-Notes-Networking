### 10.3.2 \[Đáp ứng\] Hệ điều hành được đề xuất phải hoàn toàn tương thích với phần cứng, phần mềm ứng dụng, cơ sở dữ liệu, phần mềm lớp giữa, các phần mềm và công cụ của bên thứ ba đề xuất.

> VnResource HRM cam kết hệ điều hành đề xuất hoàn toàn tương thích với phần cứng, phần mềm ứng dụng, cơ sở dữ liệu, middleware và các công cụ bên thứ ba trong toàn bộ kiến trúc hệ thống.
>
> Proxy / Load Balancer sử dụng RHEL 9.x trên nền tảng CPU x86-64, tương thích hoàn toàn với Nginx, WAF, Docker/Kubernetes và các công cụ monitoring như Grafana/Prometheus.
>
> Application Server sử dụng Windows Server 2022, tương thích đầy đủ với .NET Framework, .NET 7/.NET Core, IIS, Redis Cache, JWT Authentication và các thành phần HRM Application.
>
> Database Server sử dụng Windows Server 2022 kết hợp SQL Server 2019 Standard trở lên, hỗ trợ AlwaysOn Availability Group, SSMS, backup/restore và High Availability.
>
> Mobile và công cụ tích hợp tương thích với Firebase, REST API, OAuth2/OpenID Connect và các nền tảng Android/iOS hiện đại.
>
> Toàn bộ stack được triển khai trên kiến trúc CPU x86-64 phổ biến, hỗ trợ VMware, Hyper-V, AWS, Azure, Docker và Kubernetes.
>
> Các hệ điều hành đề xuất đều là phiên bản enterprise phổ biến, còn trong thời gian hỗ trợ chính thức và đã được kiểm chứng rộng rãi trong các môi trường triển khai quy mô lớn.
