### 10.1.2 Nhà thầu đề xuất và mô tả mô hình logic và vật lý triển khai hạ tầng phần cứng đề xuất.

> Giải pháp VnResource HRM được thiết kế theo kiến trúc multi-tier, hỗ trợ triển khai linh hoạt trên môi trường On-Premise, Private Cloud hoặc Hybrid Cloud, đảm bảo hiệu năng, tính sẵn sàng cao (HA) và khả năng mở rộng trong tương lai.

##### 1. Mô hình logic (Logical Architecture)

> Kiến trúc logic gồm các lớp chính:
>
> Presentation Layer: Web Browser, Mobile App, API Client
>
> Application Layer: Web Application, REST API, Workflow Engine, Integration Service
>
> Integration Layer: ESB/API Gateway kết nối ERP, CRM, eKYC, Core System
>
> Data Layer: SQL Server, Redis Cache, File Storage/S3
>
> Hệ thống được thiết kế stateless, hỗ trợ load balancing, scale-out và triển khai độc lập từng service/module.

##### 2. Mô hình vật lý (Physical Architecture)

> Mô hình vật lý gồm:
>
> Firewall/WAF và Reverse Proxy
>
> Load Balancer (Nginx/HAProxy/F5)
>
> Application Server Cluster (Active/Active)
>
> SQL Server Cluster (AlwaysOn Active/Passive)
>
> Redis Cache Cluster
>
> File Server hoặc S3 Object Storage
>
> DR Site phục vụ Disaster Recovery
>
> Toàn bộ hệ thống hỗ trợ:
>
> High Availability (HA)
>
> Disaster Recovery (DR)
>
> Horizontal Scaling
>
> Zero-downtime deployment
>
> Kubernetes/Docker deployment
>
> Monitoring & Centralized Logging
>
> Kiến trúc được thiết kế mở, dễ mở rộng và đáp ứng yêu cầu vận hành liên tục cho hệ thống HRM quy mô lớn.
