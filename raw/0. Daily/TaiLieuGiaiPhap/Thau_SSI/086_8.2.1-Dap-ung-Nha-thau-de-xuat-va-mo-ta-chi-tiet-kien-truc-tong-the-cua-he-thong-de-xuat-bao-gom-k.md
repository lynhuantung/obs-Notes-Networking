### 8.2.1 \[Đáp ứng\] Nhà thầu đề xuất và mô tả chi tiết kiến trúc tổng thể của hệ thống đề xuất bao gồm: kiến trúc về ứng dụng, kiến trúc hệ thống, kiến trúc tích hợp và kiến trúc cơ sở dữ liệu. 

##### Kiến trúc ứng dụng (Application Architecture)

> ![[image127.png]]
>
> Hệ thống HRM được thiết kế theo mô hình phân tầng (Layered Architecture), bao gồm:
>
> Presentation Layer:\
> Các ứng dụng Web MVC, Employee Portal, Mobile API, Web Services phục vụ người dùng và tích hợp hệ thống.
>
> Business Layer:\
> Xử lý nghiệp vụ theo từng phân hệ như Nhân sự, Chấm công, Tiền lương, Bảo hiểm, Tuyển dụng, Đào tạo, KPI, Ký số điện tử...
>
> Data Layer:\
> Sử dụng Repository Pattern và Entity Framework để truy xuất và quản lý dữ liệu.
>
> Infrastructure Layer:\
> Cung cấp các dịch vụ nền tảng như bảo mật, logging, middleware, cache Redis, lưu trữ file và tiện ích hệ thống.

##### Kiến trúc hệ thống

> ![[image128.png]]
>
> Môi trường vận hành
>
> Hệ thống HRM được triển khai trên nền tảng IIS (On-Premise) và hỗ trợ Kubernetes (K8s) cho nhu cầu mở rộng trong tương lai. Ứng dụng hiện tại vận hành trên .NET Framework 4.6.2 với ASP.NET MVC, đồng thời các dịch vụ mới được phát triển theo kiến trúc microservices sử dụng .NET 8 / ASP.NET Core Web API.
>
> Hệ thống sử dụng Redis Sentinel nhằm đảm bảo khả năng High Availability và tăng hiệu năng truy cập dữ liệu. Các tác vụ nền được xử lý thông qua Windows Service và cơ chế TaskSchedule tự động. trong khi hệ thống báo cáo được xây dựng bằng HighCharts ở frontend kết hợp SSRS và custom reporting ở backend.
>
> Phân vùng URL (URL Routing)
>
> Hệ thống sử dụng mô hình subdomain theo tenant nhằm hỗ trợ multi-tenant và phân tách dịch vụ rõ ràng.
>
> HRM Main Web:\
> https://{tenant}-main.vnrlocal.com/
>
> Employee Portal:\
> https://{tenant}-portal.vnrlocal.com/
>
> HR Service:\
> https://{tenant}-hr.vnrlocal.com/
>
> System Service:\
> https://{tenant}-sys.vnrlocal.com/
>
> Cơ chế này giúp dễ dàng mở rộng, quản lý và cấu hình độc lập cho từng khách hàng.
>
> Bảo mật
>
> Hệ thống áp dụng cơ chế xác thực bằng token kết hợp Redis Cache để quản lý session và tăng hiệu năng truy cập. Mật khẩu người dùng được mã hóa bằng MD5 hash kết hợp custom encryption.
>
> Các endpoint public hỗ trợ cơ chế AllowAnonymousRequest theo nhu cầu tích hợp. Ngoài ra, các thông tin nhạy cảm như connection string được mã hóa thông qua cấu hình IsEncryptData = true nhằm đảm bảo an toàn dữ liệu hệ thống.

##### KIẾN TRÚC TÍCH HỢP (Integration Architecture)

> ![[image129.png]]
>
> Hệ thống HRM hỗ trợ tích hợp 2 chiều với các hệ thống bên ngoài thông qua lớp Integration Service Layer, tách biệt với Core HRM nhằm đảm bảo tính ổn định, bảo mật và dễ mở rộng.
>
> Hệ thống hỗ trợ các chuẩn tích hợp:
>
> REST API (JSON)
>
> SOAP/Web Service
>
> File Exchange (CSV/JSON)
>
> CDC (Change Data Capture)
>
> Các hệ thống có thể tích hợp gồm:
>
> ERP
>
> BHXH / TS24
>
> MISA
>
> Mobile App
>
> Data Platform / MDM
>
> Dữ liệu hỗ trợ đồng bộ:
>
> Hồ sơ nhân viên
>
> Chấm công
>
> Tiền lương
>
> Bảo hiểm
>
> KPI
>
> Master Data
>
> Hệ thống áp dụng các cơ chế:
>
> OAuth2 / JWT / API Key
>
> Retry xử lý lỗi
>
> CorrelationId / TraceId
>
> Audit Log
>
> Upsert & Idempotent API
>
> Monitoring và giám sát tích hợp sử dụng:
>
> Prometheus
>
> Grafana
>
> Alerting & Transaction Tracing
>
> Kiến trúc hỗ trợ:
>
> Real-time Integration
>
> Batch Processing
>
> Multi-tenant
>
> Replay/Reprocess dữ liệu
>
> Scale-out mở rộng theo nhu cầu

##### KIẾN TRÚC CƠ SỞ DỮ LIỆU (Database Architecture)

> ![[image130.png]]
>
> Hệ thống HRM sử dụng Microsoft SQL Server 2019 Standard trở lên, triển khai trên Windows Server 2019 theo mô hình High Availability gồm 2 node Active/Passive, hỗ trợ AlwaysOn Availability Group hoặc Log Shipping/Mirroring nhằm đảm bảo khả năng failover và vận hành liên tục.
>
> Kiến trúc dữ liệu được thiết kế theo mô hình tập trung:
>
> SQL Server đảm nhiệm xử lý dữ liệu nghiệp vụ chính
>
> Redis Cache dùng cho session, token, lookup và config nhằm giảm tải truy vấn
>
> File Server (NFS) dùng lưu trữ file dùng chung giữa các ứng dụng
>
> S3/Object Storage hỗ trợ lưu trữ tài liệu và backup dài hạn khi triển khai cloud
>
> Hệ thống áp dụng các cơ chế bảo mật dữ liệu:
>
> Không truy cập trực tiếp Database từ bên ngoài
>
> Toàn bộ truy cập thông qua Application Layer
>
> Mã hóa dữ liệu nhạy cảm bằng AES-256
>
> Mật khẩu mã hóa SHA-256 kết hợp salt
>
> Audit log toàn bộ truy cập
>
> Data masking cho môi trường test/dev
>
> Database hỗ trợ UTF-8/Unicode, đảm bảo khả năng lưu trữ tiếng Việt và đa ngôn ngữ đầy đủ.
