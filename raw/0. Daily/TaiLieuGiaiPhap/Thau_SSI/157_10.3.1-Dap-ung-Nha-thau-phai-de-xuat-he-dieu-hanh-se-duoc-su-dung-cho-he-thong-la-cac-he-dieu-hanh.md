### 10.3.1 \[Đáp ứng\] Nhà thầu phải đề xuất hệ điều hành sẽ được sử dụng cho hệ thống là các hệ điều hành được sử dụng phổ biến và đã được kiểm chứng như Linux, Windows, AIX. Phiên bản sử dụng phải là các phiên bản mới được phát hành và sử dụng rộng rãi trong thời gian 3 năm gần đây. (Ưu tiên hệ thống sử dụng nền tảng Redhat Linux và Windows trên CPU x86).

> VnResource HRM đề xuất sử dụng các hệ điều hành phổ biến, ổn định và còn trong thời gian hỗ trợ chính thức, phù hợp môi trường enterprise và định hướng hạ tầng của SSI.
>
> Proxy / Load Balancer: Red Hat Enterprise Linux (RHEL) 9.x trên kiến trúc CPU x86-64, sử dụng cho Nginx/HAProxy/WAF.
>
> Application Server: Windows Server 2022 Standard/Datacenter trên CPU x86-64, chạy IIS, .NET Framework và .NET 7/.NET Core.
>
> Database Server: Windows Server 2022 + SQL Server 2019 Standard trở lên, hỗ trợ AlwaysOn Availability Group và HA Cluster.
>
> DR/UAT/DEV Environment: đồng nhất nền tảng Windows Server 2022 và RHEL 9.x nhằm đảm bảo tính tương thích giữa các môi trường.
>
> Phương án thay thế được hỗ trợ:
>
> Windows Server 2019
>
> Các hệ điều hành đề xuất đều được sử dụng rộng rãi trong 3 năm gần đây, tương thích hoàn toàn với .NET, SQL Server, Redis, Docker/Kubernetes và kiến trúc hạ tầng x86-64 của SSI.
