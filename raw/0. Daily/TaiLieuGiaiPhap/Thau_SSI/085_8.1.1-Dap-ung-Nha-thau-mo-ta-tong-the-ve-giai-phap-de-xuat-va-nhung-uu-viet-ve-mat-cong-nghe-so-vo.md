### 8.1.1 \[Đáp ứng\] Nhà thầu mô tả tổng thể về giải pháp đề xuất và những ưu việt về mặt công nghệ so với các giải pháp khác trên thị trường, bao gồm nhưng không giới hạn các lĩnh vực sau đây: Kiến trúc giải pháp và nền tảng công nghệ; Tính thân thiện với người sử dụng; Sẵn sàng tích hợp với các hệ thống khác; Hỗ trợ kiến trúc hướng dịch vụ SOA; Dễ dàng trong công tác vận hành và quản trị hệ thống; Đảm bảo an toàn, bảo mật hệ thống; Tính ổn định; Tính linh hoạt trong việc đáp ứng các yêu cầu thay đổi trong tương lai; Khả năng mở rộng để đáp ứng các nhu cầu tăng trưởng của SSI; Đáp ứng hiệu năng của hệ thống và tăng trưởng dung lượng hàng năm; Khả năng làm chủ công nghệ của SSI; Lộ trình phát triển sản phẩm và các nâng cấp/ phát hành phiên bản mới trong tương lai. Khả năng ghi log lỗi rõ ràng, cấu hình các mức hiển thị lỗi khi cần để thực hiện trace lỗi

Tổng thể giải pháp và ưu điểm công nghệ --- VnResource HRM

> Giải pháp VnResource HRM được xây dựng trên nền tảng kiến trúc mở, hiện đại và hướng dịch vụ (SOA/Microservice-ready), đáp ứng khả năng mở rộng, tích hợp linh hoạt và vận hành ổn định cho các doanh nghiệp quy mô lớn.
>
> ![[image126.png]]
>
> 1\. Kiến trúc giải pháp và nền tảng công nghệ
>
> Hệ thống được thiết kế theo mô hình multi-tier architecture gồm:
>
> Presentation Layer
>
> Application Layer
>
> Data Layer
>
> Nền tảng công nghệ sử dụng:
>
> .NET Framework và .NET 7/.NET Core
>
> RESTful API / JSON
>
> SQL Server 2019
>
> Redis Cache
>
> Kubernetes / Docker-ready
>
> Load Balancer và High Availability
>
> Kiến trúc modular và stateless giúp hệ thống dễ mở rộng, nâng cấp và triển khai độc lập từng phân hệ mà không ảnh hưởng toàn hệ thống.
>
> Công nghệ sử dụng

> 2\. Tính thân thiện với người sử dụng
>
> Hệ thống cung cấp giao diện Web responsive và Mobile App, hỗ trợ:
>
> Truy cập trên nhiều thiết bị
>
> Giao diện trực quan, dễ sử dụng
>
> Cá nhân hóa giao diện theo người dùng
>
> Workflow phê duyệt linh hoạt
>
> Dashboard và báo cáo trực quan
>
> 3\. Khả năng tích hợp
>
> Hệ thống hỗ trợ tích hợp mở với:
>
> ERP
>
> MISA
>
> BHXH / AmisBHXH
>
> Mobile App
>
> Data Platform
>
> Thông qua:
>
> REST API
>
> SOAP/Web Service
>
> File Exchange
>
> CDC (Change Data Capture)
>
> API được chuẩn hóa theo OpenAPI/Swagger giúp dễ dàng tích hợp với hệ thống bên ngoài.
>
> 4\. Hỗ trợ kiến trúc SOA
>
> Hệ thống được thiết kế theo nguyên tắc:
>
> Service độc lập
>
> Loose coupling
>
> Reusability
>
> Stateless API
>
> API Gateway
>
> Integration Service Layer
>
> Cho phép triển khai, nâng cấp và mở rộng từng service riêng biệt.
>
> 5\. Vận hành và quản trị hệ thống
>
> Hệ thống hỗ trợ:
>
> Health check endpoint: theo dõi trạng thái service real-time
>
> Admin UI: cấu hình tham số, quy trình, phân quyền không cần code
>
> SSMS: quản lý SQL Server (backup, restore, query, monitoring)
>
> Multi-environment: DEV → TEST → UAT → PROD với pipeline kiểm soát
>
> Alerting: cảnh báo email khi lỗi vượt ngưỡng, phân quyền theo vai trò Dev/Ops/Admin
>
> Kiến trúc Kubernetes và Load Balancer giúp vận hành linh hoạt trên cả Cloud và On-Premise.
>
> 6\. An toàn và bảo mật
>
> Hệ thống áp dụng nhiều lớp bảo mật:
>
> JWT / OAuth2
>
> HTTPS/TLS
>
> Redis session management
>
> Mã hóa dữ liệu nhạy cảm
>
> Audit Log và TraceId
>
> API Key & Scope
>
> Toàn bộ truy cập Database đều thông qua Application Layer nhằm đảm bảo an toàn dữ liệu.
>
> 7\. Tính ổn định và hiệu năng
>
> Hệ thống được thiết kế:
>
> HA Active/Passive: DB Failover tự động (AlwaysOn/Log Shipping)
>
> 2 App Server song song: failover tự động khi 1 node down
>
> Redis: in-memory, latency thấp, không phụ thuộc DB
>
> Kiểm thử JMeter: 10.000 user đồng thời, ≤ 3 giây (99% thao tác)
>
> Hỗ trợ mở rộng theo chiều ngang (horizontal scaling) để đáp ứng tăng trưởng người dùng và dữ liệu trong tương lai.
>
> 8\. Tính linh hoạt và khả năng mở rộng
>
> Các module nghiệp vụ được thiết kế độc lập:
>
> Có thể triển khai riêng lẻ
>
> Tùy chỉnh workflow mà không sửa code lõi
>
> Bổ sung module mới không ảnh hưởng hệ thống hiện tại
>
> Kiến trúc mở giúp SSI dễ dàng mở rộng chức năng theo nhu cầu phát triển trong tương lai.
>
> 9\. Khả năng làm chủ công nghệ
>
> Giải pháp sử dụng các công nghệ phổ biến và tiêu chuẩn mở:
>
> .NET
>
> SQL Server
>
> REST API
>
> Kubernetes
>
> Redis
>
> SSI có thể dễ dàng:
>
> Tiếp nhận vận hành
>
> Đào tạo đội ngũ kỹ thuật
>
> Quản trị hệ thống
>
> Mở rộng hoặc tích hợp thêm hệ thống mới
>
> 10\. Lộ trình phát triển sản phẩm
>
> VnResource HRM đang được phát triển theo lộ trình:
>
> Tăng cường microservices
>
> Cloud Native & Kubernetes
>
> Mobile-first
>
> API-first Integration
>
> AI/Analytics integration
>
> Hệ thống hỗ trợ nâng cấp phiên bản định kỳ và triển khai không gián đoạn dịch vụ.
>
> 11\. Logging, Trace và giám sát lỗi
>
> Hệ thống hỗ trợ:
>
> Structured logging : JSON format, gắn traceId/correlationId per request
>
> Log levels : Info / Warning / Error / Trace --- cấu hình per module/service
>
> Centralized log : Graylog/ELK --- tìm kiếm nhanh theo traceId
>
> Exception handling Middleware global : bắt toàn bộ exception, chuẩn hóa format
>
> API History Log : Ghi lịch sử toàn bộ API call (thành công/thất bại)
>
> Metrics Prometheus: CPU, memory, request rate, error rate
>
> Alert Tự động khi error rate vượt ngưỡng
