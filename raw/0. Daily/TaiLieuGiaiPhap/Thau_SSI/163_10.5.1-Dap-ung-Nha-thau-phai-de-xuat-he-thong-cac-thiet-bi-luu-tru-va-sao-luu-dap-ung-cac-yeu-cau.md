### 10.5.1 \[Đáp ứng\] Nhà thầu phải đề xuất hệ thống các thiết bị lưu trữ và sao lưu đáp ứng các yêu cầu của hệ thống cũng như nhu cầu phát triển của SSI dựa trên việc khảo sát hệ thống lưu trữ và sao lưu hiện có của SSI.

> VnResource HRM đề xuất hệ thống lưu trữ và sao lưu theo mô hình nhiều lớp (Tiered Storage Architecture), đảm bảo hiệu năng, an toàn dữ liệu và khả năng mở rộng theo nhu cầu phát triển của SSI.
>
> Kiến trúc lưu trữ gồm:
>
> Primary Storage (Hot Data):
>
> SSD/NVMe tốc độ cao cho SQL Server, transaction log và application
>
> DB Server: tối thiểu 512GB SSD
>
> App Server: tối thiểu 240GB SSD
>
> Hỗ trợ SQL Server AlwaysOn/Log Shipping
>
> Shared File Storage:
>
> NFS/SAN/NAS dùng chung cho file hồ sơ, hợp đồng, chứng từ
>
> Hỗ trợ scale-out nhiều App Server
>
> Có thể tích hợp trực tiếp với SAN/NAS hiện có của SSI
>
> Backup Storage:
>
> Backup Full + Transaction Log định kỳ
>
> Lưu backup tại DR Site hoặc Backup Server riêng
>
> Khuyến nghị dung lượng backup tối thiểu ≥ 3 lần dung lượng database production
>
> Archive Storage:
>
> Hỗ trợ Object Storage/S3/Tape cho lưu trữ dài hạn
>
> Phù hợp backup archive 1--5 năm
>
> Giải pháp hỗ trợ:
>
> Backup định kỳ
>
> Point-in-time recovery
>
> DR replication
>
> Failover
>
> Restore theo version
>
> Tích hợp với hệ thống backup hiện có của SSI như:
>
> Veeam
>
> Commvault
>
> Veritas
>
> SAN/NAS enterprise
>
> Nhà thầu sẽ phối hợp khảo sát hiện trạng hạ tầng lưu trữ và sao lưu của SSI để:
>
> Tận dụng tối đa hạ tầng hiện có
>
> Đề xuất capacity phù hợp
>
> Tối ưu chi phí đầu tư
>
> Đảm bảo đáp ứng yêu cầu hiệu năng, HA và DR của hệ thống HRM.
