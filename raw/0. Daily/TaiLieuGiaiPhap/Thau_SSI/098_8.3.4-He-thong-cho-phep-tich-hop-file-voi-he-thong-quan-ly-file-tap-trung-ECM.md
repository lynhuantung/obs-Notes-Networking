### 8.3.4 Hệ thống cho phép tích hợp file với hệ thống quản lý file tập trung (ECM)

##### Tích hợp file với ECM --- Hỗ trợ S3/Object Storage

> VnResource HRM hỗ trợ tích hợp file toàn diện với hệ thống quản lý tài liệu tập trung (ECM) của SSI thông qua kiến trúc HRM ↔ ESB ↔ ECM, không kết nối point-to-point.
>
> Về lưu trữ file nội bộ, HRM sử dụng AWS S3 / Object Storage (môi trường Cloud) hoặc File Server NFS (On-Premise) làm backend lưu trữ document nhân sự (hợp đồng lao động, chứng chỉ, ảnh\...) với tính nhất quán cao khi scale đa node.
>
> Tích hợp với ECM hỗ trợ cả hai chiều: HRM tự động đẩy tài liệu lên ECM kèm metadata qua REST API / Multipart HTTPS hoặc SFTP/FTPS; ECM trả về document reference để HRM hiển thị mà không cần lưu file vật lý trong database HRM. Chiều ngược lại, ECM có thể đẩy tài liệu vào HRM qua Inbound API chuẩn với cơ chế idempotent, audit log và xử lý lỗi đầy đủ.
>
> Toàn bộ file được mã hóa AES-256 lưu trữ, truyền qua TLS 1.2+, kiểm soát truy cập theo RBAC và ghi audit log đầy đủ theo yêu cầu bảo mật của SSI.
