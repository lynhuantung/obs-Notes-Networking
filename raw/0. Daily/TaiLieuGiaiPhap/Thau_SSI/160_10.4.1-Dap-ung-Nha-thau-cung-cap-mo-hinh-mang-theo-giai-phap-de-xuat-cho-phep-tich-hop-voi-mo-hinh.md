### 10.4.1 \[Đáp ứng\] Nhà thầu cung cấp mô hình mạng theo giải pháp đề xuất cho phép tích hợp với mô hình mạng hiện tại của SSI.

> VnResource HRM đề xuất mô hình mạng phân vùng nhiều lớp (Network Segmentation), cho phép tích hợp linh hoạt với hạ tầng mạng hiện tại của SSI, đồng thời đảm bảo an toàn, hiệu năng và khả năng mở rộng.
>
> Mô hình mạng gồm 3 vùng chính:
>
> Public Zone:
>
> WAF / Firewall
>
> Reverse Proxy / Load Balancer (Nginx/HAProxy)
>
> Tiếp nhận truy cập HTTPS từ Internet hoặc mạng nội bộ SSI
>
> Application Zone:
>
> HRM Application Server Active/Active
>
> API Services
>
> Redis Cache
>
> Không expose trực tiếp Internet
>
> Database Zone:
>
> SQL Server Active/Passive
>
> File Server/NFS
>
> Cô lập hoàn toàn khỏi Internet
>
> Mô hình hỗ trợ:
>
> On-Premise tại Data Center SSI
>
> Cloud hoặc Hybrid Cloud
>
> VPN/MPLS giữa hội sở và chi nhánh
>
> Active Directory / LDAP / SSO
>
> ESB / API Gateway / ERP / Email Server
>
> Toàn bộ giao tiếp sử dụng:
>
> HTTPS/TLS 1.2+
>
> REST API
>
> VPN nội bộ
>
> Firewall và IP whitelist giữa các vùng mạng
>
> Kiến trúc hỗ trợ:
>
> High Availability
>
> Load Balancing
>
> Auto Failover
>
> Horizontal Scaling
>
> Disaster Recovery (DR)
>
> Giải pháp được thiết kế mở, cho phép SSI dễ dàng tích hợp thêm các hệ thống mới trong tương lai mà không cần thay đổi kiến trúc tổng thể.
