### 10.2.1 \[Đáp ứng\] Nhà thầu phải đề xuất/ khuyến nghị cấu hình phần cứng máy chủ cho tất cả các môi trường bao gồm môi trường: Production, sẵn sàng cao (HA), phòng chống thảm họa (DR), phát triển, đáp ứng yêu cầu về hiệu năng của SSI. Nhà thầu không cần cung cấp phần cứng cho SSI. 

> Đề xuất cấu hình phần cứng theo từng môi trường
>
> VnResource HRM đề xuất cấu hình hạ tầng tham chiếu nhằm đáp ứng yêu cầu hiệu năng, tính sẵn sàng cao (HA) và khả năng mở rộng của SSI. Nhà thầu không cung cấp phần cứng, chỉ thực hiện tư vấn và khuyến nghị cấu hình triển khai.
>
> 1\. Production Environment
>
> Môi trường Production triển khai:
>
> 01 Load Balancer (Nginx/HAProxy)
>
> 02 Application Server chạy Active/Active
>
> 01 Database Server Active
>
> Cấu hình khuyến nghị:
>
> App Server: 16 Cores, RAM 64 GB+, SSD 240 GB+
>
> Database Server: 16 Cores+, RAM 128 GB, SSD 512 GB+
>
> OS: Windows Server 2019/2022
>
> Database: SQL Server 2019 Standard trở lên
>
> Cấu hình đáp ứng:
>
> 5.000--10.000 user đồng thời
>
> Response time ≤ 3 giây với 99% thao tác nghiệp vụ thông thường
>
> 2\. High Availability (HA)
>
> Môi trường HA triển khai:
>
> 02 App Server Active/Active
>
> 01 Database Server Passive (AlwaysOn/Failover)
>
> Cấu hình tương đương Production:
>
> App Server: 16 Cores, RAM 64 GB+
>
> Database Passive: 16 Cores+, RAM 128 GB
>
> Hỗ trợ:
>
> Auto failover
>
> Load balancing
>
> Zero-downtime operation
>
> 3\. Disaster Recovery (DR)
>
> DR Site triển khai tối thiểu:
>
> 01 Load Balancer
>
> 01 Application Server
>
> 01 Database Server Passive
>
> Cấu hình khuyến nghị:
>
> App Server: 16 Cores, RAM 64 GB+
>
> Database Server: 16 Cores, RAM 128 GB
>
> Backup và Log Shipping từ Production sang DR
>
> Hỗ trợ:
>
> DR failover
>
> Backup/restore
>
> Business continuity
>
> 4\. Development / UAT Environment
>
> Môi trường DEV/UAT triển khai:
>
> 01 Application Server
>
> 01 Database Server
>
> Cấu hình khuyến nghị:
>
> App Server: 8 Cores, RAM 32 GB
>
> Database Server: 8 Cores, RAM 64 GB
>
> Mục đích:
>
> Development
>
> SIT/UAT testing
>
> Regression testing
