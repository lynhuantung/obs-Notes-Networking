### 8.3.3 Hệ thống được đề xuất phải có khả năng hỗ trợ khai thác thông tin theo thời gian thực hoặc theo lô thông qua các tiêu chuẩn/ phương pháp tích hợp như sau: RESTFUL API; Webhoo; ETL; Streaming (socket)

> VnResource HRM cam kết hỗ trợ đầy đủ các phương thức khai thác và tích hợp dữ liệu theo thời gian thực (real-time) và theo lô (batch), đáp ứng yêu cầu tích hợp của SSI.
>
> RESTful API:\
> Hệ thống cung cấp bộ API chuẩn REST/HTTPS với định dạng JSON đầy đủ. Hỗ trợ phân trang (cursor/offset), lọc dữ liệu theo thời gian (updated_since, from/to), xác thực OAuth2/JWT, versioning API và cơ chế trả lỗi HTTP chuẩn hóa.
>
> Webhook / Event Callback:\
> Hệ thống hỗ trợ cơ chế event-driven callback, tự động gửi HTTP POST/JSON đến endpoint được cấu hình khi phát sinh sự kiện nghiệp vụ như nhân sự mới, thay đổi tổ chức, cập nhật lương hoặc trạng thái workflow. Cơ chế tích hợp hỗ trợ retry policy, correlation ID và audit log đầy đủ thông qua ESB/API Gateway.
>
> ETL / Batch Integration:\
> Hệ thống hỗ trợ cơ chế ETL và đồng bộ dữ liệu gia tăng thông qua CDC (Watermark Timestamp, Version-based), bulk export dữ liệu theo lịch với các định dạng CSV/JSON/Parquet, đồng thời hỗ trợ backfill/replay theo Time Window. Các batch job được thiết kế chạy nền và tối ưu ngoài giờ cao điểm nhằm đảm bảo không ảnh hưởng hiệu năng hệ thống giao dịch.
>
> Streaming / Near-Realtime Integration:\
> Hệ thống hỗ trợ near-realtime và realtime integration thông qua Kafka/Message Broker, cho phép publish các sự kiện nghiệp vụ và subscribe xử lý dữ liệu theo thời gian thực với độ trễ thấp. Ngoài ra, hệ thống hỗ trợ REST API polling tần suất cao cho các nhu cầu near-realtime synchronization.
