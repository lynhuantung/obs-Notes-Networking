### 9.13.1 Tất cả API endpoints phải có xác thực (OAuth 2.0 hoặc API key) và phân quyền riêng biệt. Rate limiting per endpoint. Input validation riêng cho API, không phụ thuộc frontend validation. API key rotation định kỳ và cơ chế revoke ngay lập tức.

> Hệ thống đáp ứng, tất cả api đều được cấu hình:
>
> · Xác thực API (OAuth2, JWT, API Key)
>
> · Mã hóa dữ liệu (HTTPS/TLS)
>
> · IP Whitelist / Rate Limit
>
> · Audit log khi tích hợp
