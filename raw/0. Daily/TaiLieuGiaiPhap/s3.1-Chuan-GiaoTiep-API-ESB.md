## 3.1 Chuẩn giao tiếp và định dạng dữ liệu

Phần mềm hỗ trợ tối thiểu các kênh:

**1. RESTful API / JSON / OpenAPI 3.x (Swagger)**
- Tuân thủ HTTP/HTTPS (GET/POST/PUT/PATCH/DELETE)
- Auth: OAuth2 / API Key / JWT
- Tài liệu: endpoint, request/response schema, error codes, ví dụ mẫu

**2. Bulk Export / API Export (thay JDBC/ODBC)**
- API trích xuất theo đối tượng nghiệp vụ (nhân viên, hợp đồng, chấm công, lương, đào tạo...)
- Hỗ trợ phân trang; xử lý bất đồng bộ (async export) cho dữ liệu lớn
- Bulk export: CSV, JSON (mở rộng: Parquet/Avro theo yêu cầu)

**3. Định dạng thời gian**
- Chuẩn **ISO 8601**, luôn kèm timezone, lưu trữ UTC, chuyển đổi local khi hiển thị

**4. API trích xuất / đồng bộ**
- Pagination: limit/offset hoặc cursor
- Filter thời gian: `updated_since`, `from/to`
- Rate limit, max page size, max payload rõ ràng
- Error response: HTTP status code + JSON chi tiết

**5. Sơ đồ kỹ thuật tích hợp** (3.1.6.2)
- Sơ đồ swimlane: luồng nghiệp vụ liên phòng ban, mapping từng bước với phần mềm
- API chính: `UpdateDocument`, `UpdateInvoice` — cập nhật trạng thái về hệ thống nguồn
- Trạng thái: Pending → Approved/Rejected → Completed
- Phân định: bước user thao tác vs bước ESB tự động

## 3.2 Hỗ trợ luồng dữ liệu 02 chiều qua ESB / Message Broker

### Luồng ra (HRM → Data Platform)
Phát sinh sự kiện nghiệp vụ, đồng bộ dữ liệu giao dịch, Master Data, CDC ra ESB/Kafka/API Data Platform.

### Luồng vào (Data Platform → HRM)

**Nhóm dữ liệu nhận:**
- Master Data dùng chung (tổ chức, chức danh, danh mục, mã chuẩn hóa)
- Dữ liệu chuẩn hóa (đã làm sạch, chuẩn code list)
- Kết quả phân tích/khuyến nghị từ Data Platform

**Kênh Inbound hỗ trợ:**
- Inbound REST API (qua ESB/API Gateway)
- Inbound Messaging qua Message Broker (Kafka/RabbitMQ)

**API Inbound tối thiểu:**
```
POST /api/v1/masterdata/organizations:upsert
POST /api/v1/masterdata/positions:upsert
POST /api/v1/masterdata/codelists:upsert
POST /api/v1/masterdata/employees:upsert
POST /api/v1/recommendations:import
```

**Cơ chế an toàn:**
- Xác thực: OAuth2.0/OpenID Connect và/hoặc mTLS
- Validation schema, kiểm tra code list, FK
- Idempotent + chống trùng theo `request_id`/`correlationId`
- Upsert theo unique identifier; xử lý xung đột theo `updated_at` hoặc `version`
- Audit log: ai đẩy, lúc nào, payload metadata, kết quả, correlationId
- Quarantine bản ghi lỗi + danh sách lỗi để reprocess
