## Quản lý Metadata & Tài liệu mô hình dữ liệu

> 3.6.1 Quản trị kiến trúc dữ liệu dùng chung: Với phần mềm thiết kế riêng cho PTSC: NCC Phần mềm hỗ trợ cung cấp mô hình dữ liệu logic/physical (ERD), data dictionary (mô tả bảng, cột, kiểu, ràng buộc) đối với những dữ liệu kết nối với Data Platform của PTSC. Với phần mềm SaaS/Cloud: NCC Phần mềm hỗ trợ cung cấp data dictionary + logical schema + mapping spec/API schema phục vụ data catalog/integration.
>
> Nhà  cam kết cung cấp đầy đủ tài liệu mô hình dữ liệu (ERD/Data Model), Data Dictionary và API/Mapping Schema phục vụ tích hợp và quản trị kiến trúc dữ liệu dùng chung với Data Platform của PTSC, phù hợp với từng loại hình phần mềm triển khai.
